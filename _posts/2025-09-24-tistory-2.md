- PHP



PHP(PHP: Hypertext Preprocessor)는 HTML에 내장되어 웹 애플리케이션과 동적 웹 사이트를 구축할 수 있는 오픈 소스 서버 측 스크립팅 언어입니다.



기본 문법은 다음과 같습니다

// PHP 코드 시작

<?php

 // PHP 코드가 위치

?>

// PHP 코드 종료







- 싱글쿼터(‘ ‘)와 더블 쿼터(“ “)



싱글쿼터는 글자를 출력하고 싶을 때 사용하는 것으로 출력 예시는



echo 'Hello World';

출력 결과: Hello World



더블쿼터는 글자 안에 변수 값을 같이 넣고 싶을 때도 사용되며,



$name = "예슬";

echo "Hello $name";

출력 결과: Hello 예슬



과 같이 출력됩니다.



파이썬의 f 스트링과 비슷한 역할로 생각하면됩니다!





- 싱글 쿼터와 더블 쿼터의 차이



싱글 쿼터는 문자열만 출력하고, 더블 쿼터는 문자열+변수를 같이 출려합니다.



또, 보안상 차이가 조금 존재하는데, 이는 PHP 웹 안에서 제일 많이 보이는 SQL 쿼리 안에서 '와 "가 문자열 경계를 정하기 때문입니다.



싱글 쿼터는 문자열 안에서 변수가 해석되지 않기 때문에 PHP 레벨에서는 더 안전해 보일 수 있고, 더블 쿼터는 문자열 안에서 변수가 바로 해석되기 때문에 실수로 사용자 입력을 그냥 넣으면 위험 커질 수도 있다는 차이가 있습니다.



해킹에서는 '와 "가 입력값이 문자열의 경계를 깨고 SQL이나 명령어를 조작하는 데 쓰이기도 합니다.





- 쿠키와 세션의 기본 개념



쿠키는 웹사이트에 접속할 때 자동적으로 만들어지는 임시 파일로 이용자가 본 내용, 상품 구매 내역, 신용카드 번호, 아이디(ID), 비밀번호, IP 주소 등의 정보를 담고 있는 일종의 정보파일입니다.



쿠키라는 명칭은 파일 용량이 작고, 이용자의 방문정보들이 마치 과자를 먹으면 으레 남겨지는 과자부스러기와 같다고 해서 붙여진 이름이며, 대부분의 웹브라우저는 쿠키 기능을 갖고 있으며, 네티즌니 쿠키를 받을 것인지 아닌지를 선택할 수 있는 기능도 포함돼 있습니다.



세션은 IT 용어 사전 기준으로



- 망 환경에서 사용자간 또는 컴퓨터 간의 대화를 위한 논리적 연결.

- 프로세스들 사이에서 통신을 하기 위해 메시지교환을 통해 서로를 인식한 이후부터 통신을 마칠 때까지의 기간을 뜻합니다.



쉽게 말해 사용자와 웹사이트가 “지금 같은 사람이다”라는 걸 기억하는 방법인데, 웹사이트와 내가 지금 같은 사람이라는 걸 이어주는 끈이라고 생각하면 ㅅ됩니다.



웹은 기본적으로 HTTP는 상태가 없는 프로토콜이라서, 로그인하고 다른 페이지로 넘어가면 원래는 누군지 알 수가 없기 때문에 세션이 로그인 상태 유지를 가능하게 해주는 장치입니다.



쿠키는 브라우저 쪽에 저장되는 데이터로 보관 장소가 사용자의 PC와 브라우저라면, 세션은 서버 쪽에 저장되는 데이터로 브라우저는 단지 세션(ID) 번호표만 들고 다닙니다.



쿠키는 간단하지만 보안이 약하고, 세션은 로그인 유지용으로 보다 안전하다는 특징이 있습니다.
