2. strange-program



![](/assets/img/posts/tistory/tistory-18-22.png)



이번엔 악성 프로세스를 찾는 문제!



![](/assets/img/posts/tistory/tistory-18-23.png)



플러그인을 살펴보면, 프로세스 정보를 알 수 있는 그런 플러그인이 있다.



```
python vol.py -f volatility3\memory1.vmem windows.pslist
```



를 쳐서 프로세스 정보를 읽어보자!



![](/assets/img/posts/tistory/tistory-18-24.png)



이렇게 수많은 프로세스가 뜬다! 또, psscan을 써서 한번 더 해봐야하는데 passcan은 숨겨둔 프로세스도 뜨게 해주기 때문에 이곳엔 없지만 psscan에 있는 경우 악성 프로세스일 확률이 올라간다.



![](/assets/img/posts/tistory/tistory-18-25.png)



찾았다! pslist에는 없고, passcan에는 있으면서도 이름이 굉장 꼬롬한 친구이다. explorer.exe를 짜치게 explor3r로 바꿔둔 이름이다. 이름부터 수상하고,CreateTime = ExitTime로15:06:27 시간이 동일했다. 이는 실행 되자마자 즉시 종료한다는 뜻인데, 자식으로 두고있는 4932 프로세스가 conhost.exe (8052)인데 알아보니 conhost.exe는 원래 콘솔 창을 위한 프로세스로 explor3r.exe가 커맨드라인 명령을 실행했다는 뜻이 된다.



대충 흐름을 정리해보자면

실행 → 콘솔로 뭔가 명령 실행 → 즉시 종료 이런? 흐름으로 진행된 듯 하다.



```
python ..\vol.py -f memory1.vmem windows.cmdline --pid 344
```

플러그인을 통해서 실행 당시의 커맨드 목록을 출력해보고자 했는데



![](/assets/img/posts/tistory/tistory-18-26.png)



아무것도 안 떠서 알아보니 빨리 종료되어서 그런지 cmdline 정보가 커맨드에 안 남았을 확률이 있다고 한다.



그렇기 때문에 프로세스의 실행 덤프 파일을 추출해 볼 수 있는



```
python ..\vol.py -f memory1.vmem windows.dumpfiles --pid 344
```

dumpfiles 플러그인을 써보면



![](/assets/img/posts/tistory/tistory-18-27.png)



또 안 뜬다.. 리트라이로 가상주소로 덤프



```
python ..\vol.py -f memory1.vmem windows.dumpfiles --virtaddr 0xe70bd241f080
```



![](/assets/img/posts/tistory/tistory-18-28.png)



킹받게도 뜨지 않는 모습을 볼 수 있다.



![](/assets/img/posts/tistory/tistory-18-29.png)



결국 물어봤는데 filescan을 한번 써보라고 한다!



![](/assets/img/posts/tistory/tistory-18-30.png)

드디어 오프셋 덤프가 떠서 오프셋으로 덤프를 하려고 한다. 오프셋으로 덤프를 하는 이유는 --pid 344로 덤프할 때는 프로세스 구조체를 통해 파일을 찾는데,explor3r.exe는 이미 종료돼서 프로세스 구조체가 정리됐거나 불완전한 상태로 pid로는 못 찾기 때문이다.



filescan을 쓰면 프로세스랑 상관없이 메모리에 남아있는 파일 객체 자체를 스캔해 프로세스가 종료돼도 파일 데이터는 메모리에 남아있을 수 있기 때문이라고 한다. 그래서 파일 객체의 오프셋을 직접 찾아서 그 주소로 덤프하는 것이었다!



```
python ..\vol.py -f memory1.vmem windows.dumpfiles --virtaddr 0xe70bd1209a30
```

로 덤프해보면



file.0xe70bd1209a30.0xe70bd1803c70.ImageSectionObject.explor3r.exe.img 파일이 추출된다!



덤프한 이미지 파일의 MD5를 구하기 위한 명령어가 있다고 해서



```
Get-FileHash -Algorithm MD5 .\file.0xe70bd1209a30.0xe70bd1803c70.ImageSectionObject.explor3r.exe.img
```
